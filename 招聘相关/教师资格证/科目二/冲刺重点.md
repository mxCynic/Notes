## 中学教学
### 教学的意义
教学是学校教育中最**基本**的活动
德智体美劳的**基本**途径
### 中学教学的任务
1. 引导学生掌握科学文化基础知识和基本技能。
2. 发展学生智力,培养学生的创造能力。
3. 增强学生体力,提高学生的健康水平。
4. 培养学生高尚的审美情趣,养成良好的思愚品德,形成科学的世界观。
5. 关注学生的个性发展。
记忆方法:**德智体美加个性发展**

### 教学过程的本质
1. 教学过程是一种认识过程
2. 教学过程是一种特殊的认识过程
	认识的间接性、交往性、教育性、有领导的认识(引导性)、简捷性
	(套路杨教你记:“**教育局的领导进行间接交往**“)
3. 教学过程也是一个促进学生身心发展的过程
教学过程是一个认识过程,发展过程,交往过程的统一

### 教学过程的基本阶段(阶段不等于环节)
**引领巩运查**
1. 引起学习动机----激发兴趣和求知欲
2. 领会知识
	感知教材----形成表象
	理解教材----形成概念与理论
3. 巩固知识----防止遗忘,达到保持
4. 运用知识----形成技能技巧
5. 检查学习效果---及时反馈

### 教学过程的规律
(**四个统一**)
1. 间接经验与直接经验相统一
2. 掌握知识和发展智力(能力)相统一
3. 传授知识与思想品德教育相统一
4. 教师主导作用与学生主体作用相统一
(直间统一;智知统一;德知统一;二主统一)
[中学教学](中学教学.md)
### 知识和智力(能力)之间的关系
掌握知识是发展能力的基础,能力发展是掌握知识的必备条件(意思是掌握知识<->能力发展,他俩是充要条件)

### 传授知识和思想品德教育在教学中的关系
两者是相互统一的
- 学生思想的提高以**知识为基础**
- 引导学生对所学知识产生积极的**态度**才**能**使他们的思想得到**提高**
- 学生思想的**提高又**推动他们积极的**学习**知识
记忆加粗的部分
积极态度->思想提高->积极学习->知识是基础
三点就是3个箭头

### 教学的基本环节(环节不同于阶段)

1. 备课(教材,学生,计划)
2. 上课
3. 布置和检查作业(代表份量有难度,规定时间常查改)
4. 课外辅导(从实际补充,态度积极,效果要提高)
5. 学业成绩的检查和评定(效度,信度,难度,区分度)
### 教学原则
**寻找直发巩力,进行科学理财**
1. **直观性原则(硬件+软件)**
	-  正确选择直观教具和现代化教学手段
	- 直观要与讲解相结合
	- 重视运用直观性语言  
	  直观性教学是手段不是目的,他只能让学生形成对知识**表象**的理解
2. **启发性原则(主动独立创造民主)**
	-  调动学生学习的主动性
	- 启发学生独立思考发展学生的逻辑思维能力
	- 启发学生讲知识创造性地用于实际
	- 发扬教学民主
3. **循序渐进原则(系统性原则)(系统重难点,三反义词)**
    - 按教材的系统性进行教学 
    - 抓住主要矛盾,解决好重点与难点的教学 
    - 由浅入深,由易到难,由简到繁
4. **巩固性原则(理解运用各种方法)**
	1. 在理解的基础上巩固
	2. 重视组织各种复习
	3. 在扩充改组和运用知识中积极巩固
5. **因材施教原则(统一之下有区别和特长) **(教学的因材施教和德育的因材施教有区别)
	1. 要坚持**课程计划**和学科**课程标准**的统一要求
	2. 针对学生的特点进行有区别的教学
	3. 注意培养学生特长
	统一之下有区别和特长
6. **理论联系实际原则(小联在乡下培养运输技能)**
	1. 书本知识的教学要注重联系实际(小联)
	2. 重视培养学生运用知识的能力(运输技能)
	3. 正确处理知识教学与技能训练的关系(具体联系)
	4. 补充必要的乡土教材(在乡下)
	联系实际,运用知识,处理关系,补充乡土
7. **量力性原则(可接受性原则)(把握年龄特征和特点才能把握教学难度)**
	1. 重视儿童的**年龄特征**
	2. 了解学生发展的具体**特点**
	3. 恰当地把握**教学难度**
8. **科学性与思想性统一原则(保证科学+提高能力+利用内容与环节)**
	1. 教师要保证教材的科学性
	2. 结合教学内容的特点进行思想品德教育
	3. 要通过各个环节对学生进行思想品德教育
	4. 不断提高自己的业务能力与思想水平

#### 维纳-归因理论
   维纳把人们活动成败的原因归结为6个要素并将其分为3个维度
	**1. 六要素(速记:身在外界,能努力,运气难)**
		1. 能力高低
		2. 努力程度(唯一一个可控的,其他的都是不可控)
		3. 任务难度
		4. 运气好坏
		5. 身心状态
		6. 外界环境
	2. 3维度
		1. 稳定性(只有能力高低和任务难度是稳定的)
		2. 内在性(能力,努力和身心状态时内在的,其他的是外在的)
		3. 可控性(只有努力程度是可控的)
