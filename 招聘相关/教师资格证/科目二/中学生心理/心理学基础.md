## 感觉

### 概念
人脑对**直接作用**于**感觉器官**的客观事物的个别属性的**个别属性**的反应

### 感受性和感觉阈限
感受性是对于刺激物的感觉**能力**,是用感觉阈限来衡量的,
感觉阈限是能感受到某种感觉的**临界值**(比如听力,不同的人能听到的最小分贝不一样)
(他们的描述区别是,能力和值)

## 知觉
人脑对直接作用于感觉器官的客观事物的各个部分和属性的整体反应
(强调的是整体)

### 种类
1. 空间知觉
2. 时间知觉
3. 运动知觉
4. 错觉
5. 社会知觉

### 知觉的特性(重点)
1. 整体性
	强调**部分与整体**的关系
2. 选择性
	强调**对象之间**的差异,知觉**对象和背景**的关系
	影响知觉的选择性的因素(其中1-3是客观因素,后面是主观因素)
	1. 对象的绝对强度和新奇程度
	2. 对象和背景的差别
	3. 对象是否活动
	4. 知觉有无目的和任务
	5. 个体已有知识经验的丰富程度
	6. 个体的冬季兴趣爱好情绪状态
3. 理解性
	强调**经验**导致的知觉的结果的差异
4. 恒常性
	强调环境变化后,知觉的结果**不变**

## 注意
注意是心理活动对一定对象的**指向和集中**

### 种类
1. 无意注意(不随意注意)
	情不自禁,不约而同
2. 有意注意(随意注意)
	认真听课
3. 有意后注意(随意后注意)
	熟练工

### 注意的品质及影响因素(重点)
1. 稳定性
2. 广度
3. 分配
4. 转移
#### 稳定性
对同一对象或同一活动上注意的所能**持续的时间**
狭义上针对同一对象,
广义上针对同一活动

印象稳定性的因素
1. 主体状态
	理解深刻,兴趣浓厚,态度积极,身体健康
	精力充沛,心情愉快,意志坚强
2. 对象的特点
	对象的强度,持续时间,复杂性和活动

#### 广度
注意力的广度也叫注意的范围,
同一时间内能清楚的把握对象的数量

影响注意力的广度的因素
1. 对象的特点(对象,客观)
	注意对象的组合排列
2. 个人知觉活动的任务和知识经验(个人,主观)

#### 分配
同一时间内把注意力指向不同的对象

影响注意力的分配的因素
1. 同时进行的两种活动中必须有一种是熟练的
2. 同时进行的集中活动之间的关系也很重要

#### 转移
**主动的**讲注意力的对象(活动)转移到另一个对象(活动)

影响因素
1. 原来注意的强度
2. 新的注意对象的特点
3. 个体神经过程的灵活性
4. 明确的信号提示

## 记忆
记忆是人脑对过去经验的保持和再现
记忆通过**识记,保持和回忆**着三个环节在人脑中积累和保存个体经验的心理过程

### 影响遗忘的因素(重点)
1. 识记材料的意义和作用
2. 识记材料的数量
3. 学习程度
4. 识记材料的序列位置(近因效应,首因效应)

### 遗忘的原因
1. 痕迹衰退说
2. 干扰抑制说(前摄抑制(前面的记得好), 倒摄抑制(后面的记得好))
3. 动机性遗忘说(考前焦虑,演讲焦虑)
4. 提取失败说(话到嘴边说不出来)


### 如何依据记忆规律合理安排和组织教学(简答,重点)
1. 合理安排教字
	1. 学校在排课时应避免把性质相近的读程排在一起
	2. 教师要保证学生的课间休息
	3. 教师应控制每堂课的信息投入量
2. 回学生提出具体的识记任务
3. 使学生处于良好的情绪和注意状态
4. 充分利用无意识记的规律组织教学
5. 使学生理解所学内容并把它系统化
6. 培养学生良好的记忆品质(精确、敏捷、持久、准备) ，
担提高其记忆能力
速记:
	时间紧,具体记,心情好,
	无规律,系统化,品质高
### 依据记忆规律组织复习(简答,重点)
1. 及时复习
2. 复习方式多样化
3. 运用多种感官参与复习
4. 尝试回忆与反复识记相结合
5. 合理分配复习时间
6. 掌握复习的“量” (最佳记忆效果的150%)
速记:
	多积(及)分,反复量

## 思维
思维是人脑对客观现实的**间接和概括**的反应,
它所反映的是客观事物共同的本质的特征和内在联系

### 创造性思维的培养(简答)
1. 激发学生的学习动机,培养学生学习兴**趣**和求知欲
2. 改**变**传统的**评**定学习成绩的观念,鼓励学生创造性行为
3. 培养学生的发**散**性思维和聚**合**思维的能力
4. 引导学生积极参与创造性活**动**

## 问题解决

### 过程
发现问题->理解问题 -> 提出假设 -> 检验假设

### 影响问题解决的因素(重点,背)
1. 问题的特征
2. 功能固着(就是看到某个对象惯用的用途后,很难想到其他用途)
3. 反应定势(用最熟悉的方式作出反应,老登思维)
4. 酝酿效应(暂时搁置,稍后解决)
5. 其他:原型启发,动机强度,迁移能力,情绪状态
