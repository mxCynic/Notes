### 中学教学的任务
1. 引导学生掌握科学文化基础知识和基本技能。
2. 发展学生智力,培养学生的创造能力。
3. 增强学生体力,提高学生的健康水平。
4. 培养学生高尚的审美情趣,养成良好的思愚品德,形成科学的世界观。
5. 关注学生的个性发展。

#### 间接经验与直接经验相统一 
人类获得知识的途径:
直接经验:即人类在实践中亲自获得的经验;
间接经验:即他人的认识成果,即书本知识。
学生认识的主要任务是学习间接经验。
学习间接经验必须以学生个人的直接经验为基础。

#### 掌握知识和发展智力(能力)相统一(发展性规律)
掌握知识与发展智力是学校教学中的主要任务。如何处理这两者之间的关系,
一直是各派教学理论争论的一个焦点。也是当前教学理论与实践应该解决的
一个基本问题。

教育史上两种学派的观点
形式教育派:重能力的培养
实质教育派:重知识的传授

所谓发展性规律,是指在教学过程中,在传授知识的同时,影响着学生智力的
发展;学生智力的发展又影响着他对知识的进一步学习。

##### 知识与能力之间的关系
**掌握知识是发展能力的基础,能力发展是掌握知识的必备条件。知识与智力(能力)的相互转化,**
一般来说,应注意以下条件:
(1) 传授给学生的知识应该是科学的规律性的知识;
(2)必须科学地组织教学过程;
(3)重视教学中学生的操作性活动,培养学生的参与意识和能力,提供学生积极参与实践的时间和空间;
(4)培养学生良好的个性品质,重视学生的个别差异。
，'(套路杨教你记一一科学的规律和过程;重视主体和个性)

#### 传授知识与思愚品德教育相统一
**即教学的教育性规律**,或称教书与育人相结合规律,是指在教学过程中,
不管施教者的主观意识如何,是否自觉,学生在接受知识的同时都容观地受到一
定政治立场、世界观、方法论的影响,受到一定意识形态、伦理道德观念的熏
陶,接受着一定的思想教育。

教学中,学生学习活动本身也具有巨大的教育力量;
充分利用良好的班集体的教育力量;
教师具有较高的科学文化水平,教学能力和思愚水平。

#### 教师主导作用与学生主体地位辩证统一
##### 教师的主导作用集中体现在三个转化上:
(1)认知过程的转化,使学生从不知到知;
(2)感情过程的转化,提高学生学习的自觉性,引导学生从不爱学到爱学、乐学;
(3)能力过程的转化,引导学生把知识运用于实际,形成技能技巧。

##### 如何正确理解学生在教学中的主体地位?(简答、辨析、材料分析)
**学生主体地位:学生是学习的主体,指的是学生是教学过程中学习任务的承担**
**者。学生的主体地位体现在教学的全过程。**
调动学生的学习主动性是教师有效地教学的一个主要因素。
从教学认识来看,学生是认识的主体,教师组织的一切教学活动,都要通过学
生来进行和落实。
教学效果、教学质量也要体现在学生认识的转化和行为变化的结果上

##### 教学过程中,摆正两者之间关系(良性的师生关系):
(1)教师应该充分发挥自己教的主导性。
(2)充分发挥学生的主体性,引导学生参与确定学习目标、学习
计划,积极主动地进行学习。在学习过程中自觉地进行自我调控。
(3)师生之间友爱平等

### 教学的基本环节
五个基本环节
1.  **备课**
    钻研教材,了解学生,制定教学计划
2. **上课**
    教学目标明确;内容正确;方法得当;表达清晰;重点突出;
    组织严密;课堂氛围热烈;态度从容;板书有序
3. **布置和检查作业**
   - 作业内容要符合教学大纲和教科书的要求,要有**代表性**,有助于学生固知识,形成技能,培养能力;
   - 作业**分量**要**适当**,**难易**要适度;
   - 布置作业要提出明确要求,并**规定**完成的时间;
   - 教师应**经常检查和批改**学生的作业。
    口诀:**代表分量有难度,规定时间常查改**
4. **课外辅导** 
   - 从辅导对象实际出发,确定辅导内容和措施 
   - 课外辅导是对课堂教学的补充,不能把主要精力放在课外辅导上  
   - 辅导目的要明确,采用启发式教学,充分调动学生的积极性  
   - 教师要注意态度,师生平等  
   - 加强思想教育和学习方法的指导,提高辅导效果
    口诀:从实际补充,态度要积极,效果有提高

### 教学原则(重中之重)
1. 直观性原则
	-  正确选择直观教具和现代化教学手段
	- 直观要与讲解相结合
	- 重视运用直观性语言  
	  直观性教学是手段不是目的,他只能让学生形成对知识**表象**的理解
2. 启发性原则
	-  调动学生学习的主动性
	- 启发学生独立思考发展学生的逻辑思维能力
	- 启发学生讲知识创造性的用于实际
	- 发扬教学民主
3. 循序渐进原则(系统性原则)
    - 按教材的系统性进行教学 
    - 抓住主要矛盾,解决好重点与难点的教学 
    - 由浅入深,由易到难,由简到繁
      系统,中难点,反义词
4. 巩固性原则
	1. 在理解的基础上巩固
	2. 重视组织各种复习
	3. 在扩充改组和运用知识中积极巩固
5. 因材施教原则
	1. 要坚持**课程计划**和学科**课程标准**的统一要求
	2. 针对学生的特点进行有区别的教学
	3. 注意培养学生特长
	统一之下有区别和特长
6. 理论联系实际原则
	1. 书本知识的教学要注重联系实际
	2. 重视培养学生运用知识的能力
	3. 正确处理知识教学与技能训练的关系
	4. 补充必要的乡土教材
	联系实际,运用知识,处理关系,补充乡土
7. 量力性原则(可接受性原则)
	1. 重视儿童的年龄特征
	2. 了解学生发展的具体特点
	3. 恰当地把握教学难度
	了解年龄特征+学生特点;把握难度
8. 科学性与思想性统一原则
	1. 教师要保证教材的科学性
	2. 结合教学内容的特点进行思想品德教育
	3. 要通过各个环节对学生进行思想品德教育
	4. 不断提高自己的业务能力与思想水平
		保证科学+提高能力+利用内容与环节
8大点口诀:寻找直发巩力,进行科学理财

### 教学方法的分类

#### 讲授法
讲授**不是填鸭**
基本要求包括
1. 讲授内容要有科学性,系统性,思想性
2. 注意启发
3. 讲究语言艺术

#### 谈话法
基本要求包括:
1. 要准备好问题和谈话计划
2. 提出的问题有要明确,能引起思维的活跃,问题的难易要因人而异
3. 要善于启发诱导
4. 要做好归纳,小结,是学生的知识系统化科学化,并注意纠正一些不正确的认识
   帮助他们准确的掌握知识(聊天后要归纳总结)
#### 演示法
**主体是老师**
基本要求包括:
1. 要做好演示前的准备
2. 要使学生明确演示的目的,要求与过程.主动积极自觉的投入到演示的观察与思考
   要让他们知道要看什么,怎么看,需要思考什么问题
3. 通过演示,使所有学生都能看清楚准确的感知实验对象,并引导他们感知过程中进行综合分析

#### 实验法
**主体是学生**
基本要求包括
1. 实验开始前,教师要把实验的内容,目的,步骤,要求以及注意事项告知学生
2. 实验进行中,教师要巡视实验情况,及时指导
3. 实验结束后,教师要对实验进行总结并指导学生写出实验报告

#### 练习法
基本要求包括:
1. 使学生明确练习的目的与要求,掌握练习的原理和方法
2. 精选练习材料,适当分配分量,次数和时间,练习的方式要多样化,循序渐进,逐步提高
3. 严格要求

#### 讨论法
基本要求包括:
1. 讨论的问题要有吸引力
2. 要善于在讨论中对学生进行启发引导
3. 做好讨论小结

### 教学组织形式的概念

#### 班级授课制(基本形式)
特征(简答)
1. 以班为单位集体授课
2. 内容统一
3. 进度统一
4. 时间统一
5. 分科教学

优缺点:

| 优点              | 缺点                |
| --------------- | ----------------- |
| 有利于大面积培养人才,提高教育 | 难以满足学生个性化学习需求     |
| 有利于发挥教师的主导作用    | 容易造成理论与实际相脱节      |
| 有利于班集体的教育作用     | 不利于学生创新精神和实践能力的培养 |
| 有利于教学管理和检查      |                   |

#### 贝尔-兰卡斯特制(导生制)
背景:师资不足,经费不足,同时大量的学生普及教育
形式:在老师和学生之间有一个导生,辅助老师教学,检查,考试
#### 道尔顿制
废除年级和班级

#### 文纳特卡制
1919年美国教育家华虚朋

课程分为两部分:
1. 学科(数学,英文,语文等)
2. 活动(音乐,艺术,活动等)

#### 设计学习法
重视教学活动的社会和道德的因素
优点:发挥学生的主动性和积极性,培养学生的合作精神
缺点:忽视了知识的系统性和逻辑性,对知识概念缺少整体的认知和把握

#### 特朗普制
做法:把**大班上课,小班谈论,个别作业**三种教学组织形式结合起来
特点:在一定程度上突破了集中化,同步化和标准化的刻板印象模式,兼顾了**小班教学和班级授课**的特点

#### 复式教学
在乡村存在
一个班级里一个老师同时对不同年级的学生教授不同的课程
#### 合作学习
分工合作,注重团队
