## 二、学科知识速通（约 40 分钟，只背带 ★ 的）

### 2.1 数学分析（必考）

- ★**等价无穷小（求极限第一选择）**：`sin x ~ x`、`tan x ~ x`、`arcsin x ~ x`、`1-cos x ~ x²/2`、`ln(1+x) ~ x`、`e^x-1 ~ x`、`(1+x)^α-1 ~ αx`。
- ★**两个重要极限**：`lim(x→0) sin x / x = 1`；`lim(x→∞)(1+1/x)^x = e`。
- 求极限三板斧：代入 → 等价无穷小／约分因式 → 洛必达（**仅限 0/0 或 ∞/∞**）。
- ★**介值定理**：f 在 [a,b] 连续，m≤μ≤M，则存在 ξ∈[a,b] 使 f(ξ)=μ。
  推论（零点定理）：f(a)·f(b)<0 ⇒ 存在 ξ 使 f(ξ)=0。
  **证明"有且只有一个实根"两步**：① 零点定理证存在；② 求导说明函数单调，证唯一。
- ★**可导**：f 在 x₀ 可导 ⇔ `lim(Δx→0)[f(x₀+Δx)-f(x₀)]/Δx` 存在，且**左右导数相等**；可导必连续，连续不一定可导。分段函数在分界点可导 → 列"连续 + 左导=右导"两个方程，解 a,b。
- ★**定积分与面积**：曲线 y=f(x) 与 y=g(x) 所围面积 = `∫|f(x)-g(x)|dx`（先求交点定上下限，再判断谁在上）。
  常用：`∫xⁿdx = xⁿ⁺¹/(n+1)+C`、`∫e^xdx = e^x+C`、`∫(1/x)dx = ln|x|+C`、分部积分 `∫u dv = uv - ∫v du`。
- 级数：几何级数 `Σqⁿ` 收敛 ⇔ `|q|<1`；p-级数 `Σ1/nᵖ` 收敛 ⇔ `p>1`；比较判别法、比值判别法。
  递推数列（如 aₙ₊₁ = aₙ + f(n)）用**累加法**求通项。
- 奇偶性：偶函数图象关于 y 轴对称，奇函数关于原点对称（★注意：**奇函数的导函数是偶函数**，所以它的图象关于 y 轴对称——"偶函数的导函数关于 y 轴对称"反而是错的）。

### 2.2 高等代数（必考）

- ★行列式：2 阶 `ad-bc`；3 阶用对角线法则；**|MN| = |M|·|N|**（2023 下直接考）。
- ★**矩阵的秩**：初等行变换化阶梯形，非零行数即秩；也是行（列）向量组最大线性无关组的个数。
- ★**齐次方程组 Ax=0 的基础解系含 n − r(A) 个向量**（n 为未知数个数，r 为秩）。2024 下直接考。
- ★**解的判定**：Ax=b 有无穷多解 ⇔ `r(A) = r(A|b) < n`；非齐次无解 ⇔ `r(A) < r(A|b)`。
  → 2023 下"有无穷多解求 k"：一般先看**系数行列式 = 0** 求出 k 的候选值，再代回验证秩。
- ★**特征值与特征向量**：由 `|λE − A| = 0` 求特征值 λ；再把 λ 代回 `(λE − A)x = 0` 解出非零解即特征向量。**特征向量不能是零向量**，选项里有 (0,0) 直接排除。
- 矩阵可逆 ⇔ `|A| ≠ 0` ⇔ 满秩；向量组是空间的一组基 ⇔ 线性无关且向量个数 = 空间维数。
- 整数矩阵证明套路（2024 下）：`A⁻¹ = A*/|A|`，而伴随矩阵 A* 的每个元素都是 A 的整数元素构成的代数余子式（整数），已知 |A|=±1，故 A⁻¹ 仍是整数矩阵。

### 2.3 空间解析几何（必考）

- ★平面 `Ax+By+Cz+D=0` 的**法向量 n=(A,B,C)**。
  - 两平面**平行** ⇔ 法向量平行（对应系数成比例）；
  - 两平面**垂直** ⇔ `n₁·n₂ = 0`；
  - 相交但不垂直 ⇔ 不平行也不垂直。（2024 上直接考）
- 直线方向向量 `s=(l,m,n)`；`直线⊥平面 ⇔ s∥n`；`直线∥平面 ⇔ s·n=0`。
- 点到平面距离：`d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)`。
- ★向量积 `a×b` 同时垂直于 a、b，模长 `|a||b|sinθ`（**"垂直于两向量"用来求法向量最好用**）。
- ★**四面体体积**：`V = (1/6)|(AB×AC)·AD|`，即三个棱向量的混合积除以 6。
- ★**点绕直线旋转成圆**：圆 = **球面** ∩ **平面**。
  球面：到定点（圆心）距离 = 半径；平面：过该点且垂直于旋转轴。两方程联立即为答案（2024 下原题提示"曲面与平面联立"）。
- ★二次曲面标准形识别：
  - 椭圆抛物面 `z = x²/a² + y²/b²`（一次项只有一个，另两项平方同号）
  - 单叶双曲面 `x²/a² + y²/b² − z²/c² = 1`（两个正号一个负号）
  - 椭圆柱面 `x²/a² + y²/b² = 1`（缺 z）
  - 抛物柱面 `y² = 2px`（缺一个变量且有一次项）

### 2.4 概率与统计（必考，且最容易拿满）

- ★**二项分布条件**：n 次独立重复试验、每次只有两个结果、每次成功概率恒定。
  → 2024 下"抛一枚硬币 5 次，正面向上"符合；测身高、测电池寿命、掷骰子点数是 6（多结果且非重复计数）都不符合。
- ★分布列与期望：`E(X) = Σ xᵢpᵢ`；`D(X) = E(X²) − [E(X)]²`。
- ★**分布函数 F(x) = P(X≤x)**：单调不减、右连续，X→−∞ 时 0、X→+∞ 时 1；离散型画**阶梯图**（2024 上骰子题：X 取 ±1，各 1/2，F(x) 是两级阶梯）。
- 古典概型：`P = 有利结果数 / 总结果数`。**"至少连续 k 次"这类题老老实实枚举**（2024 下"5 天至少连续 3 天下雨"：32 种等可能结果中有 8 种符合 → 1/4）。
- 数据描述：方差越大越不稳定（2023 下比语文／数学／英语／政治的方差，比的是**波动大小**）。

### 2.5 初中数学 + 数学史（单选送分）

- ★**反比例函数 y = k/x 的三个易错点**：
  ① `k ≠ 0`（k 不能为零）；
  ② k>0 时，必须说"**在每一个象限内** y 随 x 增大而减小"，不能笼统说"y 随 x 增大而减小"；
  ③ 图象是**双曲线（两支）**，不是一条连续不断的曲线。
- ★7–9 年级**不要求**的内容：解一元三次方程、二元一次不等式组（属高中）。要求：用有理数估计无理数的范围、画一次函数图象等。
- ★数学史：**负数概念最早见《九章算术》**；刘徽（割圆术、《九章算术注》）、祖冲之（圆周率）、杨辉三角、笛卡尔（坐标系）、牛顿／莱布尼茨（微积分）。
- 集合与数的分类：实数 = {有理数, 无理数}，有理数 = {整数, 分数}，无理数 = {无限不循环小数}。

## 三、课程与教学知识必背句（30 分钟能背完）

**课标数字（三套卷反复用到）**

- ★核心素养"三会"：会用数学的**眼光观察**现实世界；会用数学的**思维思考**现实世界；会用数学的**语言表达**现实世界。
- ★初中阶段核心素养 9 个表现：抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识。
- ★四基：基础知识、基本技能、基本思想、基本活动经验；四能：发现、提出、分析、解决问题的能力。
- ★课程内容四大领域：数与代数、图形与几何、统计与概率、综合与实践。
- 课程性质：数学是研究数量关系和空间形式的科学；义务教育数学课程具有**基础性、普及性、发展性**。
- 基本理念：人人都能获得良好的数学教育，不同的人在数学上得到不同的发展。

**高频简答／论述考点（直接背框架）**

- ★**几何直观的内涵与作用**：内涵——运用图表、图形描述和分析问题，把复杂问题直观化、简明化；作用——帮助理解数学概念与关系、启迪思路、发现结论、辅助证明与表达（数形结合的载体，是"看得见的推理"）。
- ★**函数与方程的联系**（以一次函数和一元一次方程为例）：方程 `kx+b=0` 的解 ⇔ 函数 `y=kx+b` 图象与 x 轴交点的横坐标；两个函数图象交点横坐标 ⇔ 对应方程组的解。教学价值：数形结合，用"形的直观"理解"数的运算"。
- ★**预设与生成**：预设——课前对教学目标、内容、活动、可能出现情况的规划；生成——课堂中随学生真实反应动态产生的资源。关系——预设是生成的基础和保障，生成是预设的补充与超越；二者辩证统一，教师要有弹性预案、善于捕捉并利用生成性资源。
- ★**项目式学习的完整过程与作用**：① 选题与情境（明确真实问题，激发动机）→ ② 制定方案（分组、分工、规划步骤，培养规划意识）→ ③ 实施探究（收集数据、动手操作、合作交流，落实四基四能）→ ④ 成果展示（表达与交流，会用数学语言）→ ⑤ 评价反思（多元评价，指向核心素养）。
- ★**习题设计重视整体性与针对性的举措**：整体性——围绕单元目标系统设计、由易到难形成层次序列、兼顾知识与素养、与教学评一致；针对性——对准重难点和易错点、结合学情分层（基础／变式／拓展）、类型多样（开放题、实际问题）、及时反馈纠错。
- ★**"讲过的会、没讲过的不会"的原因与对策**（2023 下论述题）：
  原因——只教结论不教过程；例题教学"讲一题是一题"缺少变式；学生被动接受、缺少自主探究；未揭示数学思想方法，缺乏迁移训练。
  对策——暴露思维过程、重视概念和原理的形成；用变式训练与一题多解／多题一解；创设问题情境让学生自主探究合作交流；渗透转化、数形结合、分类讨论等思想方法；分层作业、及时评价。
- ★**教学难点／教学难度的依据**：主要依据学生的**接受能力与已有认知水平**（最近发展区），同时兼顾课标要求、内容本身抽象程度。
- ★**三类"学生现实"举例**（2023 下）：生活现实——购物打折、水电费阶梯计价；数学现实——已有的一次函数、比例关系；其他学科现实——物理的速度公式、地理的等高线。
- 合情推理：先观察一组等式发现规律，再据此计算 → 培养**推理能力**（归纳、类比、猜想）。
- 教学材料选取原则：贴近学生现实，让学生经历"从现实情境中抽象出数学知识和方法"的过程。

## 四、主观题答题模板（今晚重点背这个）

### 4.1 简答／论述通用结构（7 分题写 4–6 行，15 分题写 3 段）

`定义/原文表述` → `解释（为什么）` → `教学价值/如何落实 + 具体例子`

写论述题时**每段开头亮一句课标式判断句**（如"几何直观是……的重要表现"），再展开，阅卷老师找点给分。

### 4.2 案例分析题（20 分）四步走

1. **总评**：甲乙两位教师的教学都／分别体现了……（一句话对比定性：是否以学生为主体、是否经历探究过程、是否渗透思想方法、目标达成度）。
2. **分评甲**：优点（……）+ 不足（只给结论、包办替代、缺少学生活动、情境脱离生活）。
3. **分评乙**：优点（创设情境、动手操作、合作交流、猜想—验证—证明完整过程、问题驱动）+ 可改进处（时间把控、个体差异、追问深度）。
4. **结合题目要求的学科作答**（如 2024 上要求"给出勾股定理的一种证明"、2024 下要求"证明距离相等 + 补充性质"）——这部分是纯数学，务必写"已知、求证、证明"三件套，图形关系写清楚：等腰三角形"三线合一"（顶角平分线、底边上的中线、底边上的高互相重合），两腰上的高／中线相等、底角平分线相等、底边中点到两腰距离相等等。

### 4.3 教学设计题（30 分）万能七段框架

1. **教材分析**：本节内容在初中"图形与几何／数与代数"领域的地位，与前后知识的联系，内容本质。
2. **学情分析**：学生已有知识经验、认知特点、可能遇到的困难。
3. **教学目标**（写三维或素养导向）：
   - 知识与技能：理解／掌握……，能运用……；
   - 过程与方法：经历……的探究过程，体会数形结合／分类讨论／转化思想；
   - 情感态度价值观（核心素养）：激发兴趣，发展几何直观／推理能力／应用意识。
4. **教学重点与难点**：重点＝核心概念或定理；难点＝抽象概括、探究过程的展开。
5. **教学过程**（写足细节，这是给分主区）：
   - ① 情境导入（生活实例／复习旧知／数学故事，并写**设计意图**）；
   - ② 新知探究：**问题串** → 学生动手操作／测量／剪纸／小组合作 → 猜想 → 验证 → 推理证明 → 归纳结论（每步写"设计意图"）；
   - ③ 例题精讲 + 变式练习（2–3 题，由易到难）；
   - ④ 课堂小结（知识 + 方法 + 思想）；
   - ⑤ 分层作业。
6. **板书设计**：标题 + 核心概念／定理 + 例题区 + 图形。
7. **教学评价设计**：课堂观察、提问、练习反馈、作业，体现教学评一致。

### 4.4 三套卷的教学设计题，直接练这三个课题

- **切线长定理 + 尺规作图（2023 下）**：过圆外一点 P 作切线——① 连接 OP；② 以 OP 为直径作圆（作 OP 中点 M，以 M 为圆心、MO 为半径画圆）；③ 两圆交点即切点 A、B；④ 连 PA、PB 即所求。切线长定理：从圆外一点引圆的两条切线，**切线长相等**，且这一点与圆心的连线**平分两条切线的夹角**（PA=PB，∠APO=∠BPO；证明用 HL 证 △OAP≌△OBP，因为 OA⊥PA、OB⊥PB、OA=OB、OP=OP）。
- **角的平分线的性质（2024 上）**：角平分线上的点到角两边的**距离相等**；反之，到角两边距离相等的点在角平分线上。尺规作法：以 O 为圆心画弧交两边于 M、N；分别以 M、N 为圆心、大于 ½MN 的长为半径画弧，两弧交于 P；作射线 OP 即为角平分线。探究路径：轴对称性 → 猜想 → 度量验证 → 证明（AAS）→ 归纳。
- **合并同类项（2024 下）**：同类项＝所含字母相同且相同字母的指数也相同；合并同类项＝系数相加、字母和指数不变（依据**乘法分配律**）。教学过程：从生活情境（如苹果计数、图形面积）抽象 → 用分配律说明算理 → 归纳法则 → 例题与变式 → 小结。
